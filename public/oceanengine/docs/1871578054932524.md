# 获取组织维度视频列表（ebp）

支持按 ebp_id 查询该组织下的素材 mid 列表；查询条件与返回字段与现有 adv 维度素材列表接口对齐

# 请求地址

https://api.oceanengine.com/open_api/v3.0/tools/ebp/material/list/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1871578054932524)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

e.printStackTrace();

# 工作台组织管理——解绑账户NEW

解绑组织绑定的账户

# 请求地址

https://api.oceanengine.com/open_api/v3.0/ebp/group_bind_account/delete/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1873738023776650)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

# 请求方法

POST

# Header

字段

类型

描述

Access-Token

string

Content-Type

string

# 请求参数

字段

类型

描述

enterprise_organization_id

number

工作台组织ID

accounts

object[]

选择需要解绑的账户范围

account_type

string

account_ids

number[]

通过指定业务账户ID解绑，单次传入上限1000个

group_queries

object[]

通过全选组织下所有账户解绑

group_id

number

query_type

string

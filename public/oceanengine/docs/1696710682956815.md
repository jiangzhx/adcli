# 操作日志查询

可查询巨量营销、巨量本地推、巨量千川后台操作日志，默认查询最近7天的数据，最多查询跨度为一个月。

当前一次最多支持查询2000条日志数据，超过2000条返回的分页信息可能存在不准确的问题，建议您缩短查询时间（7天以内）。

当应答参数中返回search_log_id时，表明该条操作日志返回信息较多，详细信息需调用【[获取操作日志详情](https://open.oceanengine.com/labels/43/docs/1854930515444873?origin=left_nav)】接口获取

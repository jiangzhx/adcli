# 编辑关键词调控任务

更新形式为增量更新（仅针对于预期调整的字段入参，不预期更新的字段不需要设置），其中关键词更新为全量更新

参数适用场景及生效校验条件同 【创建关键词调控任务】

# 请求地址

https://api.oceanengine.com/open_api/v3.0/oc_project/tools_keyword/update/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1865800083438596)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

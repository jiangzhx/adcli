# 批量添加投放项目下素材

批量添加投放项目下素材

# 请求地址

https://api.oceanengine.com/open_api/v3.0/oc_project/material/create/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1854929666566346)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

# 请求参数

字段

类型

描述

advertiser_id

number

客户id

project_id

number

项目id

video_material_list

object[]

视频素材信息，单次追投最多可添加200个素材（总素材量，包含视频、图片、图文）

image_mode

string

视频素材类型，允许值：

video_id

string

视频ID，可通过[【获取视频素材】](https://open.oceanengine.com/doc/index.html?key=ad&type=api&id=1696710601820172)或【获取账户可用的组织视频列表】接口获得

video_cover_id

string

视频封面图片ID，可通过[【获取图片素材】](https://open.oceanengine.com/labels/7/docs/1696710601254912)接口获得

item_id

number

注：当aweme_id传入时有效

抖音短视频ID，通过[【获取抖音主页视频】](https://open.oceanengine.com/labels/7/docs/1729982871844879)或 [【获取抖音授权关系】](https://open.oceanengine.com/labels/7/docs/1729983667746823)获取主页视频或合作授权视频

video_hp_visibility

string

视频素材主页可见性设置，该参数只针对非抖音视频生效，可选值:

guide_video_id

string

引导视频id

image_material_list

object[]

图片素材信息，，单次追投最多可添加200个素材

image_mode

string

images

string

图片ID

image_id

string

图片ID，可通过[【获取图片素材】](https://open.oceanengine.com/labels/7/docs/1696710601254912)接口获得

carousel_material_list

object[]

图文素材信息

carousel_id

string

图文id，可通过【[获取图文素材](https://open.oceanengine.com/labels/34/docs/1773554026740736)】接口获得

item_id

string

抖音图文id，需从【[获取创编可用的抖音图文素材](https://open.oceanengine.com/labels/34/docs/1812353010729227)】接口获取item_id传入

注意：投放抖音图文素材时，只需要传入item_id，不要传入carousel_id（2个同时传入只会使用item_id）

video_hp_visibility

string

trial_play_material_list

object[]

试玩素材信息

app_play_uri

string

试玩/直玩素材uri，可通过【[获取试玩/直玩素材列表](https://open.oceanengine.com/labels/7/docs/1836615534374475)】获取可用于创编的素材

guide_video_id

string

通过【[上传视频](https://open.oceanengine.com/labels/34/docs/1696710600730639)】接口上传引导视频，获取引导视频的video_id

引导视频ID，引导视频时长≥5s，文件≤100M

title_material_list

object[]

标题信息

title

string

标题

instant_play_material_list

object[]

直玩素材信息

app_play_uri

string

试玩/直玩素材uri，可通过【[获取试玩/直玩素材列表](https://open.oceanengine.com/labels/7/docs/1836615534374475)】获取可用于创编的素材

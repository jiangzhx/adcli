# 更新视频

通过此接口，用户可以批量更新素材视频的名称。

# 请求地址

https://api.oceanengine.com/open_api/2/file/video/update/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1696710605909004)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)[MCP调用](https://open.oceanengine.com/labels/7/docs/1847394521222599)

# 请求方法

POST

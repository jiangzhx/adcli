# 标准项目下获取可用深度优化方式

通过本接口获取到的深度优化方式仅适用于标准项目

# 请求地址

https://api.oceanengine.com/open_api/v3.0/event_manager/dbt/get/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1865818869111811)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

# 请求方法

GET

# 【智擎版】标准项目调控任务报表实时数据数据变动消息推送

根据创建订阅任务时设置的触发规则条件，订阅账户下存在触发事件时则会根据设定间隔进行推送（创建任务时无间隔设置提醒则为实时变动推送）

定向调控任务、关键词调控任务消耗指标变动推送感知为实扣口径，素材任务为应扣口径

# 回调地址

订阅任务设置回调地址

# 请求参数

## 基础信息

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| message_id | string | 消息ID，唯一标识 |
| subscribe_task_id | number | 订阅任务ID |
| advertiser_ids | number[] | 本服务类型一次只返回一个投放账户id |
| account_relation | object | 账号对应关系，包含所有的授权关系 |
| core_user_ids | number[] | 消息下发的投放账户是被哪些用户授权的 |
| service_label | string | 订阅服务类型，枚举值：report.stdschedule.activeprogram |
| publish_time | number | 消息实际产生时间，毫秒时间戳 |
| timestamp | number | 毫秒时间戳，本条消息实际推送时间，获取推送数据列表时无该参数数据 |
| nonce | number | 随机数，和timestamp组合防重放，获取推送数据列表时无该参数数据 |
| data | object | 推送数据信息，订阅服务类型不同，返回结构不同 |
| user_id | number | 触发事件的账户ID，营销场景即为投放账户ID |
| event | string | 子事件类型，枚举值： SCHEDULE 调控任务事件 |
| content | object | 事件内容 |
| project_id | number | 聚合周期内发生指标变更的调控任务对应的项目ID |
| schedule_ids | number[] | 聚合周期内发生指标变更的调控任务列表 |

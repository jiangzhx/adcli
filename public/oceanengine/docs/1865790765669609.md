字段

类型

描述

advertiser_id

project_id

audience_type

string[]

district_audience

object

地域定向设置，若目标调控定向类型为地域，需设置具体定向

district

string

geolocation

object[]

radius

number

name

string

long

float

lat

float

region_version

string

city

number[]

省市或者区县列表

location_type

string

gender_audience

string

若目标调控定向类型为性别，需设置具体定向

age_audience

string[]

若目标调控定向类型为年龄，需设置具体定向

delivery_setting

object

cpa_bid_rate

float

表达愿意提升xx%的出价

计算当前所填比例下，对应的调控出价/深度转化出价，公式为（1+xx%）*原出价/深度转化出价

精度：整数

出价范围：(0,400)

deep_bid_rate

float

计算当前所填比例下，对应的调控出价/深度转化出价，公式为（1+xx%）*原出价/深度转化出价

精度：xx为整数

出价范围：(0,400)

roi_goal_rate

float

表达愿意降低xx%的ROI系数目标

计算当前所填比例下，对应的调控出价/深度转化出价，公式为（1-xx%）*原出价/深度转化出价

精度：xx为整数

出价范围：(0,80)

cpa_bid

float

表达愿意提升出价的绝对值

出价范围：大于当前项目设置，且最终出价不超过项目预算

deep_bid

float

表达愿意提升深度出价的绝对值

出价范围：大于当前项目设置，且最终出价不超过项目预算

roi_goal

float

表达愿意提升roi系数的绝对值

出价范围：大于0，且小于当前项目设置

setting_type

string

调控类型

first_roi_goal_rate

float

表达预期降低的roi系数（绝对值）- 首日roi

seven_roi_goal_rate

float

表达预期降低的roi系数（绝对值）- 7日roi

first_roi_goal

float

愿意降低xx%的ROI系数目标（百分比）- 首日roi

计算当前所填比例下，对应的调控出价/深度转化出价，公式为（1-xx%）*原ROI系数目标

seven_roi_goal

float

愿意降低xx%的ROI系数目标（百分比）- 7日roi

计算当前所填比例下，对应的调控出价/深度转化出价，公式为（1-xx%）*原ROI系数目标

name

string

字符长度限制：50字符，2个英文字符占1个字符

默认值：定向溢价任务n_YYYY_MM_DD_HH:MM:SS

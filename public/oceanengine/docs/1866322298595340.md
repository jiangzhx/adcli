# 查询IOS应用列表

最新查询IOS应用列表

# 请求地址

https://api.oceanengine.com/open_api/v3.0/ios_app/list/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1866322298595340)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

GET

# 请求参数

字段

类型

描述

account_id

number

账户id

account_type

string

search_key

string

搜索关键字 itunes_id或者应用名称

可以为空，可以传中文/英文，长度不超过50

status

string

search_type

string

account_asset_query_scope

string

hierarchy

string

若入参账户类型为营销账户，则不传默认查adv直属升级版组织id的应用

若入参账户类型为升级版组织，则不传默认查当前组织及下属组织的所有应用

可选值:

publish_time

object

应用发布时间

start_time

number

end_time

number

asset_generation

string

page

number

不传默认为1，最小为1

size

number

不穿默认为10，最小为1，最大为100

# 根据mid查询同主体账户下修复建议列表

注意：本接口仅支持根据advertiser_id、拒审material_id，查询该拒审素材已被应用到哪些同主体账户下&已产生修复建议，注意：

# 请求地址

[https://api.oceanengine.com/open_api/v3.0/reject_material/ai_repair/cross_account/get/](https://api.oceanengine.com/open_api/v3.0/reject_material/ai_repair/cross_account/get/)[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1828071966256128)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)[MCP调用](https://open.oceanengine.com/labels/7/docs/1847394521222599)

# 请求方法

# 应答字段

字段

类型

描述

code

number

返回码,详见 [【附录-返回码】](https://open.oceanengine.com/labels/7/docs/1696710760866831)

message

string

返回信息,详见 [【附录-返回码】](https://open.oceanengine.com/labels/7/docs/1696710760866831)

data

json

json返回值

advertiser_id

number

拒审素材所属投放账户

material_id

number

拒审素材id

ai_repair_id

number[]

拒审素材在当前账户下的修复id，可能有多个

reject_material_related_repair_tasks

object[]

原账户&拒审素材相关的同主体账户及修复建议

related_advertiser_id

number

关联的同主体客户id

related_ai_repair_ids

number[]

修复建议id列表，获取后可用于[采纳接口](https://open.oceanengine.com/labels/7/docs/1827080076923659)

request_id

string

请求日志id

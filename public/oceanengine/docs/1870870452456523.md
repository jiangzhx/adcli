# 【智擎版】标准项目状态实时推送

当您订阅的投放账户下，存在智擎版标准项目状态变更时，会为您下发消息通知，通知范围：

# 回调地址

订阅任务设置回调地址

# 关联API接口

https://api.oceanengine.com/open_api/v3.0/std_project/list/

# 请求方式

POST

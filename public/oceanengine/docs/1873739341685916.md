# 工作台组织管理——绑定账户NEW

工作台组织绑定账户，支持通过主体、客户ID方式绑定

# 请求地址

https://api.oceanengine.com/open_api/v3.0/ebp/group_bind_account/create/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1873739341685916)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

# 请求方法

POST

# Header

字段

类型

描述

Access-Token

string

Content-Type

string

# 请求参数

字段

类型

描述

enterprise_organization_id

number

bind_model

object

绑定方式

apply_bind_type

string

company_id

number

主体公司ID，apply_bind_type = COMPANY_BIND时有效且必填

customer_id

number

accounts

object[]

绑定的账户范围，account_ids、all_company_account、all_customer_account三选一

account_type

string

account_ids

number[]

传入主体公司/客户ID下所需绑定对应业务线业务账户ID，单次请求上限1000个。

all_company_account

bool

通过主体公司ID绑定方式下设定主体公司ID管理的指定业务线下所有账户

all_customer_account

bool

通过客户ID绑定方式下设定客户ID管理的指定业务线下所有账户

only_active

bool

是否只绑活跃账户

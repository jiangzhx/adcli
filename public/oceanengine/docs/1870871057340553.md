# 【智擎版】标准项目配置实时变更

当您订阅的投放账户下，存在智擎版标准项目修改记录时，会为您下发消息通知，通知范围：

# 回调地址

订阅任务设置回调地址

# 关联API接口

https://api.oceanengine.com/open_api/v3.0/std_project/list/

# 请求方式

POST

# 请求Header

字段

类型

描述

Content-Type

string

X-Open-Signature

string

# 请求参数

## 基础信息

类型

描述

number

number

number

number

number[]

account_type

string

content

object

number[]

landing_type

string

# 删除投放项目下素材

本接口支持删除一个投放项目下存在的素材，请注意

# 请求地址

https://api.oceanengine.com/open_api/v3.0/oc_project/material/delete/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1854929995241483)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

string

page

number

页码，默认值：1，当且仅当material_type=VIDEO 视频、IMAGE 图片、CAROUSEL 图文、TRIAL_PLAY_MATERIAL试玩素材时支持传入

page_size

number

页面大小，允许值：10, 20, 50, 100，默认值：10，仅material_type=VIDEO 视频时支持传入

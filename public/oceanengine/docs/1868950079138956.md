# 获取升级版巨量引擎工作台账户星广联投任务已投稿达人信息

获取升级版巨量引擎工作台账户星广联投任务已投稿达人信息

仅支持通用版星广联投任务，不兼容短剧版

# 请求地址

https://api.oceanengine.com/open_api/v3.0/tools/ebp/star_task/task_author/get/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1868950079138956)[SDK下载](https://open.oceanengine.com/labels/7/docs/1773083358100557)

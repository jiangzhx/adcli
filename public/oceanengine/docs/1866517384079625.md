# 获取账户可用品牌行业信息NEW

获取账户可投品牌行业信息，目前支持查询云图品牌行业

# 请求地址

https://api.oceanengine.com/open_api/v3.0/dpa/brand/adv_auth/industry/get/[可视化调试](https://open.oceanengine.com/tools/visual_debug.html?docId=1866517384079625)

# 请求方法

GET

# Header

字段

类型

描述

Access-Token

string

# 请求参数

字段

类型

描述

account_id

number

营销账户id

origin_req

object

品牌筛选

brand_data_source

string

outer_brand_id

number

品牌数据来源方的品牌id（当前仅支持云图品牌id），对应账户可投品牌列表接口出参的outer_brand_id

* Send GET request

Map< String, Object > map = mapper.readValue(jsonStr, Map.class);
map.forEach((k, v) -> {
try {
ub.addParameter(k, v instanceof String ? (String) v : mapper.writeValueAsString(v));
} catch (JsonProcessingException e) {
e.printStackTrace();
}
});
URL url = ub.build().toURL();
​
Request request = new Request.Builder()
.url(url)
.method("GET", null)
.addHeader("Access-Token", ACCESS_TOKEN)
.build();
Response response = client.newCall(request).execute();
return response.body().string();
}
